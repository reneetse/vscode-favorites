# Favorites 1.15.4 安装与交接

本次定制版在两个 Favorites 视图的右键菜单中增加三个复制命令，支持文件、文件夹、展开的子项以及多选；多选结果按选择顺序逐行复制，并按资源 URI 去重。收藏配置格式无需迁移。

| 菜单名称 | 复制内容 |
| --- | --- |
| Copy File Name | 文件名，保留扩展名；不复制用于区分同名文件的目录标签 |
| Copy File Path | 本地和 Remote SSH 文件的绝对路径；其他 URI 资源保留完整 URI |
| Copy Relative Path | 相对于文件所属工作区根目录的路径；多根工作区不加工作区名称前缀；工作区外文件或未打开文件夹时回退为绝对路径；其他 URI 资源保留完整 URI |

菜单沿用项目现有的英文显示名称。相对路径调用 VS Code 的 `workspace.asRelativePath(uri, false)`，不以收藏文件夹作为基准。

## 其他环境安装

1. 下载 VSIX，或拉取仓库取得上述文件。
2. 在目标 VS Code 窗口打开扩展面板，选择右上角 `…` → `Install from VSIX...`（从 VSIX 安装），选择 `vscode-favorites-1.15.4.vsix`。
3. 若使用 Remote SSH、WSL 或 Dev Container，先连接目标环境，确认 Favorites 安装在对应远端环境中。当前扩展声明 `extensionKind: ["workspace"]`；每个远端环境需要分别安装。
4. 执行 `Developer: Reload Window`（开发人员：重新加载窗口），再到扩展详情确认版本为 `1.15.4`。

若目标窗口终端可使用 `code` 命令，也可从仓库根目录执行：

```sh
code --install-extension ./releases/vscode-favorites-1.15.4.vsix --force
```

这条命令须在目标 VS Code 环境中执行；给其他服务器安装时不能只在本机安装一次。
