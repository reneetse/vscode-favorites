# Favorites 1.17.1 使用说明

## 排序

默认使用“最近修改优先”。已有显式排序设置继续保留；可点击收藏视图顶部的“选择排序方式”，可选择名称升序、名称降序、最近修改优先、最早修改优先、文件类型和手动排序。设置对收藏顶层和展开的文件夹内容生效；手动排序下，顶层保留收藏顺序，文件夹内部按名称升序显示。

除手动排序外，文件夹优先。上移、下移、置顶和置底以当前可见顺序为基准，操作后切换为手动排序。修改时间取文件系统的上次修改时间，不是上次打开时间；默认每 30 秒定时刷新，也可保存文件或点击刷新更新。名称按自然数字顺序排列，例如 `note2.md` 在 `note10.md` 前面。

## 定时刷新与 NEW 标记

`favorites.refreshInterval` 设置刷新间隔（秒），默认 `30`，设为 `0` 关闭定时刷新，手动刷新仍可使用。扫描限于收藏目录，不使用即时文件监听；重叠定时任务会合并。

首次扫描将现有文件作为基线，不会把所有旧文件标新。之后发现的新增文件，在尚未显示到编辑器时使用蓝色新文件图标及 `NEW` 标记；打开后清除。标记按工作区保存，插件内移动后会跟随文件。目录临时不可用时保留状态；新的收藏目录从加入监测时建立基线。

## 跟随当前文件定位

`favorites.autoReveal` 默认 `true`。切换到当前收藏分组范围内的文件时，展开真实父目录并选中文件，编辑器保留键盘焦点。只对可见的收藏视图发起定位；隐藏视图再次显示时跟随当前文件。设为 `false` 可关闭。

定位依赖实际可展开的节点。文件被 `files.exclude` 隐藏且没有独立收藏时不会强行定位；明确收藏的排除项会保留独立入口。原生 `TreeView.reveal` 发出后没有取消接口，慢 I/O 时与立即隐藏视图的并发行为仍需宿主验收。

## 新建子文件夹

右键收藏中的文件夹或展开后的子文件夹，选择“新建子文件夹”。右键文件时，在该文件所在目录中新建。只接受单个文件夹名称，不接受路径跳转；重名时提示，不覆盖已有内容。

## 将文件移回 jack

1. 在收藏视图多选要移动的文件，右键选择“移动到文件夹…”，选择实际的 `jack` 目录。
2. 也可以把多选项直接拖到收藏视图中的 `jack` 文件夹或其子文件夹上。
3. 从子目录返回可直接使用“移到上一级目录”，目标不会依赖文件夹选择器的初始位置。
4. 操作会真正移动磁盘文件，并更新所有收藏分组中的路径；移动整个文件夹时，内部文件的收藏路径一并更新。

顶层收藏项不代表文件在磁盘上位于目录外。1.17 按真实路径将可展开的嵌套收藏归并显示，底层书签记录保留；被排除或无法经目录展开的显式收藏保留顶层入口。移到已有目录时如果物理路径未变，会显示实际目标路径；无需为了调整面板显示再次移动磁盘文件。移出所有收藏目录时补独立书签，避免文件失去入口。

在收藏视图内部拖到目录执行真实移动；拖到文件或空白位置用于调序或添加快捷项。从资源管理器或编辑器直接拖入只添加收藏：部分旧版 VS Code 不提供完整外部目录选择，应先添加收藏再在收藏视图中移动。

同名目标或多个同名源文件会在整批操作开始前拦截，不覆盖文件。批量选中的名称仅大小写或 Unicode 规范化形式不同，也会保守拦截，可改为逐个移动。文件已在目标目录时跳过；同时选择父文件夹和内部文件时只移动父文件夹一次。文件移动使用 VS Code 工作区编辑，可通过“撤销”恢复。若运行期间发生权限、磁盘或其他错误，批次可能部分完成；提示会尽量核实并列出已完成数量和路径，已完成项目的收藏路径会同步更新。中断的批次不保证生成撤销记录，请检查源、目标目录后再重试。

移动支持当前 VS Code 主机文件系统和 Remote SSH。源与目标须处于相同文件系统及远端连接中；普通网页链接和其他虚拟资源不能执行文件管理。

## 删除实际文件与文件夹

右键“删除文件／文件夹…”会删除真实磁盘内容，支持多选。确认框列出完整路径，目录包含其全部内容。优先使用回收站；不支持回收站时，必须再次确认才永久删除。取消任一确认不会自动改为永久删除。

工作区根、主目录及其上级目录禁止删除；确认期间目标身份改变会中止。只支持当前扩展主机上的普通文件和目录，拒绝符号链接及直接的虚拟/跨提供方 URI；Remote SSH 正常文件由远端扩展主机的 file URI 操作，仍受支持。元数据保存失败会与磁盘完成结果分别报告。

“从收藏中移除”只移除书签，不删除文件；嵌套的独立书签仍可单独移除。

## 操作日志

运行命令“收藏：查看操作日志”，在输出面板的 `Favorites` 通道查看 `move.request`、`move.sameDirectory`、`move.completed`、`move.failed` 和删除结果。日志记录实际源路径与目标路径，可区分没有移动、磁盘操作成功、收藏保存失败及中途失败。日志在本机，未上传到外部服务。

## 语言

打开 VS Code 设置，搜索 `favorites.language`：

| 值 | 行为 |
| --- | --- |
| `zh-CN` | 中文，默认值 |
| `en` | English |
| `auto` | 跟随 VS Code，中文界面使用中文，其他语言使用英文 |

菜单、提示、收藏视图标题及当前分组提示随设置更新，无需重载。现有分组名称和收藏内容不改名。

## 安装

安装包为 `releases/vscode-favorites-1.17.1.vsix`，其他环境已克隆仓库时无需重新编译。在仓库 `master` 分支、目标 VS Code 窗口的终端中执行：

```sh
git pull --ff-only
code --install-extension ./releases/vscode-favorites-1.17.1.vsix --force
```

也可从扩展面板选择“从 VSIX 安装”。安装后执行 `Developer: Reload Window`，确认版本为 `1.17.1`。Remote SSH、WSL 和容器需分别安装到对应目标环境。配置格式兼容旧版本，无需迁移收藏。维护者重新打包使用 `npm run build`。

## 验证边界

回归命令为 `npm test`，通过 VS Code API 适配器操作真实临时文件和临时 Git 仓库，检查批量移动、目录创建、删除确认与保护、冲突、部分失败、收藏层级、定时刷新、NEW 标记、自动定位、排序和语言切换。类型检查使用 `npm run check-types`。

这些检查不等于真实 VS Code 界面验收。安装后仍应在临时文件上确认多选拖放、目录选择器、菜单语言、撤销和剪贴板操作；不会自动搬动用户工作区里的实际文件。
